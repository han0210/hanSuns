> **프로젝트명:** nSuns Hybrid  
> **문서 버전:** v1.5 (2026-10-21, 휴식 기본값 T1·T2 60초 / v1.4 세트 완료 체크박스 UX 반영)  
> **문서 상태:** 초안 — 검토 필요  
> **기준 문서:** `docs/planning/PTS.md`, 계산 규칙은 `docs/planning/CALCULATION_RULES.md`  
> **제품 유형:** 모바일 중심 웨이트 트레이닝 웹서비스

## 1. 제품 개요

### 1.1 제품 소개

nSuns Hybrid는 nSuns 5/3/1의 근력 훈련 방식을 기반으로, 사용자 맞춤형 보조 운동과 FST-7 근비대 루틴을 통합한 운동 관리 서비스다.

사용자는 운동별 기준 중량을 입력하고 원하는 운동 종목을 선택할 수 있다.

시스템은 해당 운동의 기준 중량과 훈련 템플릿을 적용하여 세트별 목표 중량을 자동 계산한다.

운동 중에는 실제 수행 기록과 휴식 타이머를 제공하며, 기록된 데이터를 다음 훈련에 활용한다.

### 1.2 핵심 가치

**운동은 자유롭게, 중량 계산은 자동으로.**

### 1.3 제품 목표

1. 운동별 중량 계산 자동화
2. T2·T3 운동 커스터마이징
3. 운동 변경 시 자동 중량 스케일링
4. nSuns + FST-7 하이브리드 프로그램 제공
5. 세트별 운동 기록 및 휴식 타이머 통합
6. 모바일 환경에서 간편한 운동 관리

### 1.4 제품 성공 기준

- 사용자 입력 기준 중량으로 세트별 목표 중량 계산 가능
- T2·T3 운동 변경 후 자동 중량 재계산
- T3의 12회 × 7세트 규칙 유지
- 운동 기록 저장 및 복원
- 세트 완료 후 휴식 타이머 정상 작동
- 외부 유료 API 없이 핵심 기능 실행 가능

## 3. 기본 운동 프로그램

### 3.1 주간 스케줄

| 요일 | T1 | T2 | T3 — FST-7 |
|---|---|---|---|
| 월 | 벤치프레스 | OHP | 케이블 플라이 |
| 화 | 데드리프트 | 프론트 스쿼트 | 레그 컬 |
| 수 | 휴식 | — | — |
| 목 | 스쿼트 | 스모 데드리프트 | 레그 익스텐션 |
| 금 | OHP | 인클라인 벤치프레스 | 덤벨 사이드 레터럴 레이즈 |
| 토 | 바벨 로우 | 슈러그 | 랫풀다운 |
| 일 | 휴식 | — | — |

### 3.2 T1 규칙

- 요일별 기본 T1 종목 고정
- 운동별 1RM 또는 기준 중량 입력
- Training Max 기반 목표 중량 자동 계산
- 원본 nSuns의 세트·반복·중량 비율 참고
- 실제 수행 기록 저장
- AMRAP 결과에 따른 다음 주 중량 조정 지원
- 바벨 로우는 일반 5/3/1 벤치형 T1 템플릿을 재사용하고, 바벨 로우 전용 1RM·TM을 독립 관리한다 (Hybrid 규칙)
- 같은 운동(exerciseId)이 T2에서도 쓰이면 하나의 운동 프로필과 현재 TM을 공유한다 (예: 금요일 T1 OHP ↔ 월요일 T2 OHP)

**미확정 사항:** 원본 nSuns 계산표와 바벨 로우가 재사용할 벤치형 템플릿의 세트 데이터는 원본 대조 후 확정한다. AMRAP 증량은 원본 증량 범위 내 고정값 방식으로 확정했으나 구체적인 값은 미확정이다.

### 3.3 T2 규칙

- 기본 보조 운동 제공
- 사용자 운동 변경 가능
- 운동 유형별 지원 템플릿 적용 (지원 템플릿이 없는 운동은 자동 계산 보류)
- 운동별 기준 중량 관리: 서로 다른 운동은 독립, T1과 같은 운동 ID는 공통 TM 공유
- 변경된 운동에 맞춰 모든 세트 중량 자동 계산
- 실제 수행 중량 수동 조정 가능
- 종목별 마지막 기준 중량과 운동 기록 저장

**미확정 사항:** T2 자체 자동 증량 규칙과 운동 유형별 세트 비율은 미확정이며, 승인 전에는 T2 자동 증량을 적용하지 않는다.

### 3.4 T3 규칙

FST-7 기반 근비대 운동을 제공한다.

| 설정 | 규칙 |
|---|---|
| 세트 수 | 7세트 고정 |
| 목표 반복 | 12회 고정 |
| 총 목표 반복 | 84회 |
| 기본 휴식 | 30초 |
| 운동 변경 | 가능 |
| 초기 중량 | 사용자 직접 입력 |
| 이후 중량 | 7세트 모두 12회 이상 + 목표 중량 이상 수행 시 다음 세션 한 단계 증량, 그 외 유지 |
| 세트 구성 | MVP에서 변경 불가 |

T3 운동 종목이 변경되어도 12회 × 7세트 구조는 유지한다.

## 4. 핵심 사용자 흐름

### 4.1 최초 이용

1. 서비스 접속
2. nSuns Hybrid 프로그램 안내 확인
3. 운동별 기준 중량 입력
4. 기본 5일 루틴 생성
5. T2·T3 운동 확인 또는 변경
6. 자동 계산된 목표 중량 확인
7. 운동 시작

### 4.2 운동 진행

1. 오늘의 운동 확인
2. T1 세트별 목표 중량 확인
3. 실제 수행 중량 및 반복 횟수 입력 (체크 전까지 수정 가능)
4. 세트 완료 후 해당 세트의 체크박스를 직접 체크
5. 입력값 검증 → 저장 성공 시 세트 완료·잠금
6. 같은 운동에 다음 세트가 남아 있으면 휴식 타이머 자동 실행
7. 다음 세트(완료되지 않은 첫 세트) 진행
8. T2 및 T3 수행
9. 운동 종료 및 기록 저장

### 4.3 운동 커스터마이징

1. 변경할 T2 또는 T3 선택
2. 새로운 운동 종목 검색·선택
3. 저장된 운동별 기준 중량 확인
4. 기준 중량이 없다면 최초 입력
5. 목표 중량 자동 재계산
6. 사용자 확인 후 적용

기존 운동의 기록은 보존하며 다른 운동으로 변경해도 삭제하지 않는다.

## 5. 기능 요구사항

### FR-001. 운동별 기준 중량 설정

**우선순위:** P0

사용자는 운동별 기준 중량을 입력하고 수정할 수 있어야 한다.

수용 기준:

- 양수 중량 입력 가능
- kg 단위 지원
- 기준 중량 저장 및 재사용
- 최초 등록 운동은 입력 절차 제공
- 잘못된 입력값은 계산에 사용하지 않음
- 운동별 중량 기준을 독립적으로 유지

### FR-002. T1 중량 자동 계산

**우선순위:** P0

사용자 기준 중량과 T1 템플릿을 바탕으로 세트별 목표 중량을 계산한다.

수용 기준:

- 운동별 목표 중량 표시
- 세트별 반복 횟수 표시
- TM 변경 시 중량 재계산
- 운동별 중량 증가 단위로 최종 세트 중량만 반올림 (정확한 중간값은 높은 중량 선택)
- AMRAP 세트 구분
- 바벨 로우는 벤치형 T1 템플릿 재사용 지원

### FR-003. T2 커스터마이징

**우선순위:** P0

사용자는 T2 운동 종목을 변경할 수 있어야 한다.

수용 기준:

- 운동 목록에서 종목 선택
- 선택한 운동의 유형에 맞는 T2 지원 템플릿 적용
- 선택한 운동의 저장된 기준 중량 조회
- 기준 중량이 없으면 입력 요청
- 변경 즉시 목표 중량 재계산
- 이전 운동 기록 보존
- 기본 T2 운동으로 복원 가능

### FR-004. 운동 변경 시 자동 스케일링

**우선순위:** P0 — 핵심 차별화 기능

운동 변경 시 사용자가 입력한 해당 종목의 기준 중량을 이용하여 목표 중량을 자동 설정한다.

수용 기준:

- 운동별 서로 다른 기준 중량 적용
- 동일 운동 ID는 T1·T2에서 공통 TM 사용 (세트 템플릿은 티어별로 별도 적용)
- 세트 수만큼 목표 중량 자동 생성
- 기준 중량 수정 시 전체 세트 재계산
- 중량이 없는 운동에 임의의 무게 적용 금지
- 운동별 장비 중량 단위 지원
- 계산 결과 수동 수정 가능 (세트 완료 전)

### FR-005. T3 FST-7

**우선순위:** P0

T3는 12회 × 7세트로 고정한다.

수용 기준:

- 7개 세트 자동 생성
- 모든 세트의 목표 반복은 12회
- 운동 종목 변경 가능
- 운동별 작업 중량 입력
- 세트별 실제 반복 횟수 저장
- 수행 결과를 다음 훈련의 중량 조정에 활용

### FR-006. 휴식 타이머

**우선순위:** P0

세트 체크박스를 체크해 완료 저장에 성공하고, 같은 운동에 다음 세트가 남아 있으면 해당 운동 유형에 맞는 휴식 타이머를 자동 시작한다.

| 운동 | 기본 휴식 |
|---|---|
| T1 | 60초 |
| T2 | 60초 |
| T3 | 30초 |

> 2026-10-21 STEP 10 사용자 결정: T1·T2 기본 휴식을 180초·120초에서 **60초**로 변경. T3 30초 유지. 사용자가 바꿀 수 있다.

수용 기준:

- 세트 완료 체크 저장 성공 시 자동 시작 (저장 실패 시 미시작)
- 남은 시간 표시
- 일시정지 및 재개
- ±15초 시간 조절
- 휴식 건너뛰기
- 타이머 설정 저장
- 마지막 세트 완료 시 불필요한 휴식 미실행
- 브라우저 지원 범위에서 종료 알림

### FR-007. 운동 기록 관리

**우선순위:** P0

운동별 실제 수행 결과를 저장한다.

기록 항목:

- 운동 날짜
- 운동 종목
- T1·T2·T3 구분
- 세트 번호
- 목표 중량
- 수행 중량
- 목표 반복
- 수행 반복
- 완료 여부

수용 기준:

- 각 세트 기록 가능
- 각 세트마다 완료 체크박스 표시, 사용자가 세트 완료 후 직접 체크
- 체크 시 입력값을 검증한 뒤 저장하고, 저장에 성공한 경우에만 완료 상태로 잠금
- 저장 실패 시 체크되지 않은 상태로 유지하고 입력값 보존, 오류 안내 및 재시도 가능
- 완료된 체크박스는 개별 해제 불가
- 현재 세트는 완료되지 않은 첫 세트로 표시
- 세트 완료 전에는 입력값(수행 중량·반복) 수정 가능
- 세트 완료 후에는 해당 세트 기록 수정 불가 (잠금)
- 완료된 세션의 기록은 개별 수정 불가
- 기록을 다시 입력하려면 해당 운동(T1/T2/T3 중 하나)의 전체 세트를 사용자 확인 후 리셋하고 첫 세트부터 재입력
- 운동 리셋 시 같은 세션의 다른 운동 기록과 다른 세션의 기록은 변경되지 않음
- 운동 리셋 후에도 목표 중량·목표 반복과 세션 시작 시점 TM 스냅샷은 유지
- 운동 리셋으로 TM·작업 중량이 새로 생성되거나 TM 증량이 적용되지 않음
- 운동 리셋 시 해당 운동의 체크 상태와 실제 수행 기록 초기화, 다른 운동의 체크 상태와 기록 유지
- 운동별 리셋 횟수와 마지막 리셋 시각 기록
- 운동 리셋은 하루 세션이 진행 중 또는 일시 중단 상태일 때만 가능
- 완료된 세션(U-14)과 중도 종료된 세션(U-15)의 운동 리셋은 정책 확정 전까지 허용하지 않음
- 페이지를 다시 열어도 저장된 기록 복원
- 기록과 기준 중량은 구분해 저장
- 운동 종목 변경 시 기존 기록 유지

### FR-008. 자동 중량 조정

**우선순위:** P0

저장된 수행 기록을 기반으로 다음 운동의 목표 중량을 조정한다.

적용 원칙:

- T1은 AMRAP 결과에 따라 원본 nSuns 증량 범위 내 고정값으로 운동 프로필의 공통 TM 증량 (고정값 미확정, 승인 전 미적용)
- T2 자체 자동 증량 규칙은 미확정 (승인 전 미적용). T2에서 공통 TM을 별도로 중복 증량하지 않음
- T3는 7세트 모두 12회 이상 + 목표 중량 이상 수행 시 한 단계 증량, 그 외 유지
- T3 자동 감량은 MVP 범위에서 제외하고 후속 검토
- 동일 세션 완료가 중복 처리되어도 증량은 한 번만 적용
- 계산 근거 표시
- 사용자 수정 허용 (목표 중량, 세트 완료 전까지)

**세부 계산 규칙은 `CALCULATION_RULES.md`를 따르며, 미확정 항목은 해당 문서 11장에서 관리한다.**

### FR-009. 사용자 데이터 저장

**우선순위:** P0

MVP는 별도 유료 서비스를 사용하지 않는 데이터 저장 방식을 지원한다.

요구사항:

- 기준 중량 저장
- 커스터마이징 설정 저장
- 수행 기록 저장
- 휴식 타이머 설정 저장
- 저장 실패 시 사용자 안내

초기에는 회원가입 없는 로컬 저장 방식을 기본 후보로 검토한다.

최종 저장 방식은 기술 설계 단계에서 확정한다.

## 7. 예외 처리

| 상황 | 처리 방식 |
|---|---|
| 기준 중량 미입력 | 입력 요청, 계산 중단 |
| 기준 중량이 0 또는 음수 | 유효성 검사 오류 |
| 소수점 중량 | 허용 범위 및 장비 단위 검증 |
| 신규 운동 선택 | 기준 중량 최초 입력 |
| 운동 중 종목 변경 | 확인 후 변경 및 기록 보존 |
| 세트 체크 시 입력값 누락·오류 | 체크 거부, 오류 항목 안내 |
| 세트 체크 저장 실패 | 미완료 상태 유지, 입력값 보존, 재시도 안내 |
| 완료된 체크박스 해제 시도 | 해제 불가 안내, 해당 운동 전체 세트 리셋 경로 안내 |
| 완료된 세트 수정 시도 | 수정 불가 안내, 해당 운동 전체 세트 리셋 경로 안내 |
| 진행 중 운동 리셋 요청 | 확인 모달 후 해당 운동의 세트만 리셋 |
| 완료·중도 종료 세션의 운동 리셋 요청 | 현재 지원하지 않음 안내 (정책 미확정) |
| 타이머 중 화면 이동 | 가능한 범위에서 시간 상태 유지 |
| 저장 실패 | 오류 안내 및 재시도 |
| 목표 반복 미달 | 실제 반복 횟수 기록 |
| 지원하지 않는 계산 규칙 | 자동 중량 계산 보류 및 안내 |

## 8. 비기능 요구사항

### 8.1 성능

- 중량 계산은 사용자 입력 변경 시 즉시 수행
- 타이머는 경과 시간을 기준으로 동작
- 핵심 화면은 모바일 환경에 최적화
- 불필요한 외부 네트워크 요청 최소화

### 8.2 사용성

- 한국어 기본 지원
- kg 단위 기본 적용
- 운동 중 한 손 조작 고려
- 주요 버튼에 명확한 상태 표시
- 데이터 저장 여부 확인 가능

### 8.3 데이터 안정성

- 운동 기록을 임의로 삭제하거나 덮어쓰지 않음
- 자동 계산값과 사용자 수정값을 구분
- 저장된 운동별 기준 중량 유지
- 잘못된 계산으로 비정상적인 무게를 표시하지 않음

### 8.4 서비스 운영

- 무료 MVP
- 유료 외부 API 필수 의존성 없음
- 모바일 웹 환경 우선
- 브라우저별 타이머 및 저장 동작 검증

## 10. MVP 수용 기준

다음 시나리오가 모두 정상적으로 동작하면 핵심 기능 구현을 완료한 것으로 판단한다.

### AC-01. 초기 설정

사용자가 운동별 기준 중량을 입력하면 목표 중량이 계산되고 저장된다.

### AC-02. T2 변경

인클라인 벤치프레스를 다른 운동으로 변경하면 해당 운동의 입력 중량에 맞춰 모든 T2 세트의 목표 중량이 계산된다.

### AC-03. T3 변경

케이블 플라이를 다른 운동으로 변경해도 12회 × 7세트가 유지된다.

### AC-04. 휴식 타이머

T1 세트를 완료하면 기본 60초 휴식 타이머가 시작되고, 사용자가 시간을 조절할 수 있다.

### AC-05. 운동 기록

사용자가 실제 중량과 반복 횟수를 기록하고 화면을 다시 열었을 때 해당 기록이 복원된다.

### AC-06. 다음 운동 중량

운동 결과를 기반으로 다음 훈련의 목표 중량이 계산되며, 사용자가 계산 근거를 확인할 수 있다.

### AC-07. 데이터 검증

기준 중량이 입력되지 않은 운동은 임의로 계산되지 않는다.

## 13. 최종 제품 정의

**nSuns Hybrid**는 nSuns 기반 근력 훈련과 FST-7을 결합한 5일 운동 관리 웹서비스다.

사용자는 운동별 기준 중량을 입력하고 T2·T3 종목을 자유롭게 변경할 수 있다.

시스템은 변경된 운동에 맞춰 세트별 목표 중량을 자동 스케일링하며, 운동 기록과 휴식 타이머, 다음 운동의 중량 조정 기능을 제공한다.

**핵심 차별화:** 운동을 변경해도 중량을 다시 계산할 필요가 없는 사용자 경험.
