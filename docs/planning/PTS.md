## 1. 프로젝트 개요

### 1.1 서비스 소개

**nSuns Hybrid**는 nSuns 5/3/1의 근력 훈련 체계에 FST-7 근비대 루틴을 결합한 맞춤형 웨이트 트레이닝 관리 서비스다.

사용자는 자신의 운동 수행 능력에 맞는 기준 중량을 입력하고, 원하는 보조 운동을 선택할 수 있다.

시스템은 각 운동의 기준 중량과 계산 규칙을 활용하여 세트별 목표 중량을 자동으로 계산한다.

또한 세트별 운동 기록, 자동 중량 조정 및 휴식 타이머를 제공하여 훈련 과정을 통합 관리한다.

### 1.2 핵심 가치 제안

> **운동은 자유롭게 변경하고, 중량 계산은 자동으로.**

운동 종목을 변경할 때마다 세트별 중량을 직접 계산할 필요 없이, 운동별 기준 중량만 입력하면 프로그램이 자동으로 목표 중량을 설정한다.

### 1.3 서비스 목표

- nSuns 기반 근력 운동의 자동 중량 계산 제공
- T2 보조 운동의 자유로운 커스터마이징
- 운동 종목 변경 시 자동 중량 스케일링
- FST-7 근비대 루틴 자동 구성
- 세트별 휴식 타이머 제공
- 운동 수행 기록 및 점진적 과부하 관리
- 스마트폰 중심의 간편한 운동 경험 제공

## 2. Problem — 문제 정의

### 2.1 문제 배경

nSuns 5/3/1은 Training Max(TM)를 기반으로 세트별 목표 중량을 계산하는 근력 훈련 프로그램이다.

그러나 사용자가 개인의 운동 목표와 선호도에 맞게 프로그램을 변경하려 할 때 다음과 같은 불편이 발생할 수 있다.

### 2.2 핵심 문제

#### P1. 운동 종목 변경 시 중량 계산의 번거로움

사용자가 기존 보조 운동을 다른 종목으로 변경하면 해당 운동에 맞는 기준 중량과 세트별 목표 중량을 다시 설정해야 한다.

특히 세트별 강도가 달라지는 프로그램에서는 직접 계산해야 하는 부담이 발생한다.

#### P2. 근력 및 근비대 운동의 통합 관리 어려움

근력 중심의 nSuns와 근비대 중심의 FST-7을 함께 수행하려면 운동 구성을 별도로 설계하고 기록해야 한다.

#### P3. 운동 수행 기록 및 중량 조정의 번거로움

운동별 수행 중량과 반복 횟수를 기록하고 다음 운동에 적용할 중량을 관리하는 과정이 번거로울 수 있다.

#### P4. 세트별 휴식 시간 관리의 비효율성

T1, T2, T3는 훈련 목적과 강도가 다르므로 서로 다른 휴식 시간이 필요하다.

별도의 타이머를 사용하면 운동 기록과 휴식 시간 관리가 분리되는 불편이 있다.

### 2.3 핵심 문제 정의

> nSuns 이용자는 운동 종목을 자유롭게 변경하면서도 자동 중량 계산과 운동 기록의 편의성을 유지하고 싶다.

**검증 상태:** 사용자 불편에 대한 기획 가설이며, 실제 사용자 조사로 추가 검증이 필요하다.

## 3. Target — 목표 사용자

### 3.1 핵심 타깃

**nSuns를 기반으로 자신만의 운동 루틴을 구성하려는 중급 웨이트 트레이닝 이용자**

### 3.2 사용자 특성

| 구분 | 내용 |
|---|---|
| 운동 수준 | 기본적인 웨이트 트레이닝 경험 보유 |
| 운동 목표 | 근력 향상 및 근비대 |
| 운동 빈도 | 주 5일 |
| 선호 프로그램 | nSuns 5/3/1 기반 |
| 주요 요구 | 운동 커스터마이징 및 자동 중량 계산 |
| 사용 환경 | 헬스장, 스마트폰 |
| 사용 목적 | 운동 수행 및 기록 관리 |

### 3.3 핵심 사용자 시나리오

1. 사용자가 nSuns Hybrid 5-Day 프로그램을 시작한다.
2. 각 운동의 기준 중량을 입력한다.
3. T1 운동의 세트별 중량이 자동 계산된다.
4. T2 운동을 원하는 종목으로 변경한다.
5. 시스템이 변경된 운동의 기준 중량으로 세트별 중량을 다시 계산한다.
6. T3에서는 해당 요일의 FST-7 운동을 수행한다.
7. 각 세트를 완료하면 휴식 타이머가 자동으로 시작된다.
8. 사용자가 실제 중량과 반복 횟수를 기록한다.
9. 기록된 수행 결과를 기반으로 다음 운동의 목표 중량을 조정한다.

## 4. Solution — 해결 방안

### 4.1 서비스 핵심 구조

nSuns Hybrid는 세 가지 운동 단계로 구성된다.

| 구분 | 역할 | 구성 | 중량 설정 |
|---|---|---|---|
| T1 | 메인 근력 운동 | nSuns 기반 | TM 자동 계산 |
| T2 | 보조 운동 | 사용자 커스터마이징 | 운동별 기준 중량 적용 |
| T3 | 근비대 마무리 운동 | FST-7 | 수행 기록 기반 자동 조정 |

### 4.2 S1. T1 자동 중량 계산

- 운동별 1RM 입력
- Training Max 자동 계산
- nSuns 기반 세트별 목표 중량 산출
- AMRAP 수행 결과 기록
- 다음 주 목표 중량 조정

**제약:** 바벨 로우 T1은 nSuns 원본에 없는 커스텀 운동이다. 원본의 일반 5/3/1 벤치형 T1 템플릿을 재사용하고, 바벨 로우 전용 1RM·TM을 독립적으로 관리한다(Hybrid 자체 규칙).

### 4.3 S2. T2 운동 커스터마이징

사용자가 원하는 보조 운동을 선택할 수 있다.

운동 변경 시 시스템은 다음 순서로 작동한다.

1. 선택한 운동의 기존 기준 중량 조회
2. 기준 중량이 없으면 최초 입력 요청
3. 운동 유형별 T2 지원 템플릿의 세트별 강도 비율 적용
4. 목표 중량 자동 계산
5. 사용자가 중량을 수정할 수 있도록 제공

**핵심:** 운동이 변경되어도 자동 중량 계산 기능은 유지된다.

### 4.4 S3. T3 FST-7

T3는 FST-7 방식의 근비대 운동으로 구성한다.

| 항목 | 기본 규칙 |
|---|---|
| 세트 수 | **7세트 고정** |
| 목표 반복 | **12회 고정** |
| 총 목표 반복 | 84회 |
| 종목 변경 | 가능 |
| 최초 작업 중량 | 사용자 직접 입력 |
| 중량 조정 | 수행 기록 기반 |
| 휴식 시간 | 기본 30초, 변경 가능 |

사용자가 T3 운동을 변경하더라도 12회 × 7세트 구성은 유지된다.

### 4.5 S4. 세트 간 휴식 타이머

세트를 완료하면 해당 운동 단계에 맞는 휴식 타이머가 자동 실행된다.

| 운동 구분 | 기본 휴식 시간 |
|---|---|
| T1 | 60초 |
| T2 | 60초 |
| T3 | 30초 |

타이머의 핵심 기능은 다음과 같다.

- 세트 완료 후 자동 시작
- 남은 휴식 시간 표시
- 일시정지 및 재개
- 휴식 시간 ±15초 조정
- 휴식 건너뛰기
- 지원 가능한 환경에서 종료 알림
- 운동 단계별 타이머 설정 저장

### 4.6 S5. 운동 기록 및 중량 조정

사용자는 각 세트의 실제 수행 결과를 기록한다.

기록 데이터는 다음 운동의 중량 계산과 진행 상황 분석에 활용한다.

주요 기록 데이터:

- 운동 날짜
- 운동 종목
- 목표 중량
- 실제 수행 중량
- 목표 반복 횟수
- 실제 반복 횟수
- 세트 완료 여부

## 6. 핵심 차별화 전략

### 6.1 핵심 차별화 기능

**운동 종목 변경에 따른 자동 중량 스케일링**

기존 운동 종목을 변경하더라도 세트별 목표 중량을 직접 다시 계산할 필요가 없다.

시스템이 해당 운동의 기준 중량과 운동 단계별 계산 규칙을 활용하여 전체 세트의 목표 중량을 자동 설정한다.

### 6.2 보조 차별화 요소

| 구분 | 차별화 방향 |
|---|---|
| 프로그램 구성 | nSuns + FST-7 결합 |
| 운동 개인화 | T2·T3 운동 변경 |
| 중량 관리 | 운동별 독립적인 기준 중량 |
| 자동화 | 변경 운동에 맞춘 자동 스케일링 |
| 운동 수행 | 휴식 타이머 통합 |
| 기록 활용 | 수행 결과에 따른 중량 조정 |

### 6.3 경쟁 서비스 대비 포지셔닝

기존 운동 기록 앱과의 차별점은 단순히 운동 종목을 수정할 수 있다는 점이 아니다.

**운동 변경, 자동 중량 계산, FST-7 구성, 운동 기록을 하나의 흐름으로 연결하는 사용자 경험**에 집중한다.

단, 유사 기능이 경쟁 서비스에 존재할 가능성이 있으므로 독점적인 기능이라고 주장하지 않는다.

## 8. 제약 조건 및 검증 과제

### 8.1 기술적 제약

- 외부 유료 API 사용하지 않음
- 핵심 계산 로직은 자체 구현
- 운동 데이터는 사용자 입력값을 기반으로 계산
- 기록이 없는 운동의 기준 중량을 임의로 생성하지 않음
- 모바일 웹 사용을 우선 고려
- MVP는 무료 서비스로 개발

### 8.2 계산 규칙 검증

PRD 및 기능 명세 단계에서 다음 사항을 확인해야 한다.

1. nSuns 원본 T1 세트·반복·중량 비율
2. nSuns 원본 TM 및 AMRAP 증량 규칙
3. 바벨 로우 T1이 재사용할 벤치형 템플릿의 원본 세트 데이터
4. T2 운동 유형별 세트 중량 비율 및 적용 운동 범위
5. T3 FST-7 자동 증량 기준 (증량·유지 규칙 확정, 자동 감량은 MVP 제외·후속 검토)
6. 바벨·덤벨·머신별 중량 입력 및 반올림 처리

### 8.3 운동 프로그램 검증

- 고볼륨 T1·T2와 FST-7 결합에 따른 운동량 검토
- 운동일별 피로 누적과 회복 부담 검토
- 운동시간 약 60분 목표의 현실성 검토
- 사용자별 수행 능력 차이를 반영할 수 있는 조정 기능 검토

본 프로그램은 nSuns 원본과 FST-7을 결합한 자체 변형 프로그램이며, 특정 운동 효과나 부상 예방을 보장하지 않는다.

## 9. 성공 기준

### 9.1 기능적 성공 기준

- 사용자가 운동 종목을 변경할 수 있다.
- 변경된 운동의 기준 중량으로 목표 중량이 자동 계산된다.
- T3는 모든 운동에서 12회 × 7세트를 유지한다.
- 사용자가 실제 수행 중량과 반복 횟수를 기록할 수 있다.
- 세트 완료 시 휴식 타이머가 정상 작동한다.
- 저장된 운동 기록을 다음 운동에서 다시 사용할 수 있다.
- 사용자 입력 및 변경 내역에 따라 계산 결과가 일관되게 갱신된다.

### 9.2 사용자 경험 성공 기준

- 스마트폰에서 운동 중 조작하기 편리하다.
- 세트별 중량을 직접 계산할 필요가 없다.
- 운동 변경 후에도 프로그램 진행 흐름이 유지된다.
- 휴식 타이머와 운동 기록을 한 화면 흐름에서 이용할 수 있다.

## 10. 최종 PTS 정의

### Problem

nSuns 사용자가 운동 구성을 개인화할 때, 종목별 목표 중량을 다시 계산하고 운동 기록 및 휴식 시간을 별도로 관리해야 하는 불편이 있다.

### Target

nSuns 기반으로 근력과 근비대를 함께 훈련하면서 자신의 보조 운동을 자유롭게 구성하고 싶은 중급 웨이트 트레이닝 이용자.

### Solution

**nSuns Hybrid**는 운동별 기준 중량을 입력하면 T1·T2·T3의 목표 중량을 자동으로 설정하고, T2·T3 운동 변경 시에도 자동 스케일링을 유지하는 맞춤형 5일 운동 관리 웹서비스다.

FST-7(12회 × 7세트), 수행 기록, 세트 간 휴식 타이머를 통합 제공한다.
